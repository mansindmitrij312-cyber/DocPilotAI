# DocPilot AI

AI-сервис для генерации документов (резюме, договоры, заявления, коммерческие предложения) с личным кабинетом, лимитами на бесплатном тарифе, реферальной системой и экспортом в PDF.

## Стек

- **Backend:** Python 3 + Flask
- **AI:** Ollama (локальная модель `llama3.2:3b`) — бесплатная генерация без сторонних API
- **БД:** SQLite (без ORM, чистый `sqlite3`)
- **Auth:** сессии Flask + хэширование паролей (`werkzeug.security`)
- **Безопасность:** CSRF-защита (`flask-wtf`), rate-limiting (`flask-limiter`), security-заголовки, безопасные cookie
- **PDF:** `reportlab` с поддержкой кириллицы (шрифт DejaVu Sans)
- **Frontend:** чистый HTML/CSS/JS (Jinja2-шаблоны), без сборщиков — легко модифицировать

## Функционал

- Регистрация/логин, восстановление пароля по email (Gmail SMTP)
- Генерация документов через локальную AI-модель, с редактированием и удалением
- Скачивание готового документа в PDF
- Лимит 5 бесплатных генераций на аккаунт + заглушка тарифа Pro (оплата не подключена — легко добавить)
- Реферальная система: свой код у каждого юзера, бонусные генерации за приглашения
- Поиск по своим документам, адаптивный дизайн (мобильная версия)
- OG-теги для красивого превью при шаринге в соцсетях

## Установка

1. Установите зависимости:
```
pip install flask flask-wtf flask-limiter reportlab ollama python-dotenv
```

2. Установите [Ollama](https://ollama.com) и скачайте модель:
```
ollama pull llama3.2:3b
```

3. Скопируйте `.env.example` в `.env` и заполните:
   - `FLASK_SECRET_KEY` — сгенерировать: `python -c "import secrets; print(secrets.token_hex(32))"`
   - `SMTP_EMAIL` / `SMTP_PASSWORD` — опционально, для реальной отправки писем восстановления пароля (иначе ссылка просто печатается в консоль сервера — удобно для разработки)

4. Запустите:
```
python app.py
```

Сайт будет на `http://127.0.0.1:5000`.

## Важно перед продакшеном

- Сейчас используется встроенный dev-сервер Flask — для реального деплоя нужен production WSGI-сервер (gunicorn/waitress)
- Ollama требует минимум 4GB RAM на сервере — для дешёвых VPS стоит рассмотреть облачный AI API вместо локальной модели
- `FLASK_DEBUG` должен быть `False` в проде

## Структура проекта

```
app.py              — вся логика Flask-приложения (роуты)
database.py         — работа с SQLite
static/css/style.css — вся дизайн-система (неоновая тёмная тема)
static/js/main.js    — общие скрипты (счётчик, эффекты)
templates/           — Jinja2-шаблоны (base.html — общий каркас)
fonts/               — шрифт для кириллицы в PDF
```

## Что можно докрутить дальше

- Подключить реальную оплату (ЮKassa/Prodamus) вместо заглушки на `/pro`
- Перевести хранение документов на PostgreSQL при росте нагрузки
- Заменить Ollama на облачный API для более качественной генерации
